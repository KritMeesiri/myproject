** 2. Context-Aware Vulnerability Classification
Status : In Progress

A research project that integrates cybersecurity threat intelligence, computer asset information, and 
knowledge graphs to support context-aware vulnerability risk prioritization. 
The proposed framework uses Neo4j to integrate threat intelligence with asset-level context,

The system aims to identify affected assets, calculate an Environmental Vulnerability Score (EVS), 
and categorize risks into actionable levels to support security analysts.

Focus : Cyber Threat Intelligence (CTI), Knowledge Graphs, Neo4j, Vulnerability Risk Prioritization, Environmental Vulnerability Scoring
